# Cassandra 6.0 (trunk) Reference

This directory holds reference files for the unreleased Cassandra trunk (currently tracking toward 6.0).

## Contents

- [`cassandra.yaml`](./cassandra.yaml) — the **unmodified default config file** that Cassandra trunk ships with. This is the raw upstream file, useful for seeing every setting and its shipped default as of this snapshot.

There is no `cassandra-yaml.md` opinionated recommendations doc for 6.0 yet — refer to [`../cassandra-5.0/cassandra-yaml.md`](../cassandra-5.0/cassandra-yaml.md) for the current set of opinionated guidance. Those recommendations will need to be re-evaluated for 6.0 once the release stabilises.
